# Server (später)

Hier entsteht der Mehrspieler-Server: Node.js mit WebSockets. Er entscheidet über Positionen, Treffer und Beute und speichert Konten und Spielstände.

Geplantes Hosting: kleiner Cloud-Server bei Hetzner (2 vCPU, 4 GB RAM, Ubuntu, Standort Deutschland). Veröffentlichung automatisch über GitHub Actions. Zugangsdaten nur als GitHub Secrets, nie im Repository.
